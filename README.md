# Angry Judge: The Short Rant Contest

A short, funny rant about hold music, written by a program for the
[make.fun bounty "Angry Judge: The Short Rant Contest"](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046).

`main.py` (Python 3.13, no network, deterministic) writes the rant to `/output/entry.txt`:

> "Your call is important to us," the robot has said for forty minutes, which is exactly how long it takes to stop believing it. I have memorised the hold music. I hum it in the shower now. When a human finally answers, I will apologise for sounding relieved.

## Running it

```sh
python3 main.py
```

The script writes `entry.txt` into the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `/output` when that variable is not set). The file holds the rant above, exactly as written — 257 characters, inside the 400-character cap. Running it again overwrites the same file with the same bytes.
